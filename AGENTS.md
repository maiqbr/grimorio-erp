# Orientações para manutenção

Leia [docs/GUIA-DO-PROJETO.md](docs/GUIA-DO-PROJETO.md) antes de alterar este repositório. Consulte a seção da funcionalidade envolvida e os arquivos indicados nela.

Toda alteração versionada deve atualizar o guia na mesma entrega: corrija a seção afetada e acrescente uma linha concreta ao registro de mudanças. Mantenha o `README.md` e os guias específicos coerentes quando o procedimento mudar.

Este repositório é público e tem licença de uso pessoal restrito. Não inclua dados de instâncias, chaves, contatos pessoais, domínios reais nem imagens privadas. Execute `npm run check:secrets` e faça revisão manual antes de publicar.
